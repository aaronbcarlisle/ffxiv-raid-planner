# Legacy V1 Overview Tab Enumeration (Phase B gap-close)

Scope: the legacy/V1 "Overview" (`pageMode === 'overview'`) branch of
`frontend/src/pages/GroupViewContent.tsx` (lines 899-936), which mounts
`StaticHomeTab` from `frontend/src/components/static-group/StaticHomeTab.tsx`
(1811 lines). This is the only `overview` branch in `GroupViewContent.tsx` —
there is no parallel V2 slot consumer bypassing it (`slots?.overview` is the
only override point, used by tests/embeds).

Mount site: `frontend/src/pages/GroupViewContent.tsx:900-936`
```
{pageMode === 'overview' && (slots?.overview ?? (
  <>
    <PageHeader icon={...} title="Overview" subtitle="Command center for your static." />
    {currentGroup && (
      <StaticHomeTab
        group={currentGroup}
        tier={currentTier}
        onNavigate={(tab, subTab) =>
          setPageMode(tab, tab === 'goals' && subTab ? { goal: subTab } : undefined)
        }
        canManage={canManageRoster(userRole).allowed}
        onOpenRequests={() => useSettingsPanelStore.getState().open({ tab: 'recruitment', section: 'requests' })}
        onScheduleFarm={(trial) => { ...eventBus.emit(Events.MOUNT_FARM_SCHEDULE, {...}) }}
      />
    )}
  </>
))}
```

Key structural notes that affect several rows below:
- `onNavigate(tab, subTab)` only forwards `subTab` when `tab === 'goals'`
  (as `{ goal: subTab }`); a `subTab` passed for any other tab (e.g.
  `'roster'`) is silently dropped by the wrapper.
- `canManage` is computed as `canManageRoster(userRole).allowed` — **without**
  the `isAdminAccess` second argument that other legacy tabs pass
  (compare `GroupViewContent.tsx:1393`: `canManageRoster(userRole, isAdminAccess).allowed`).
- Permission model: `MemberRole = 'owner' | 'lead' | 'member' | 'viewer'`
  (`frontend/src/types/index.ts:625`); `canManageRoster()`
  (`frontend/src/utils/permissions.ts:212`) returns `allowed: true` only for
  `owner`/`lead`. `member` and `viewer` both get `canManage=false` on this
  tab — StaticHomeTab does not further distinguish member vs viewer itself.
