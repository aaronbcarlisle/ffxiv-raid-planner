> Run with the `slice-loop` skill (`.claude/skills/slice-loop/`). Never load
> `superpowers:subagent-driven-development` in this repo.

**Goal:** a manager in V2 recruits end to end without opening Settings: one Recruiting page inside the static holds the applicant inbox (with the SF1 fit tier and reasons computed for each applicant), the listing editor and link invites. Listing status becomes real on the backend (paused and closed listings leave the Finder and stop requests) for both shells. V1 changes only by that fix, the join-banner gate that goes with it, and one label fix.

**Architecture:**
- **Task 1 (RH1a, backend + two V1 fixes):** a pure `services/discovery_settings.py` (status normalisation + one `is_discoverable`) replacing the two router copies; the fit-input loader extracted from the discovery router into `services/finder_inputs.py`, batched by user id, so the join-request list can compute `fit` per waiting applicant with the SF1 engine; the `join_requests` Player Hub item; the V1 `STATUS_LABEL` fix and the `JoinRequestBanner` gate; a public release note.
- **Task 2 (RH1b, the riskiest):** the route `/group/:shareCode/recruit` under V2 (sibling route, explicit chrome matchers, `NewShell` renders the page in place of `GroupViewContent` and routes Spine/⌘K tab changes back to the static, the no-tiers gate bypassed, V1 redirects to the static), the page frame (header with the status `Select`, three URL-synced Tabs, the manager guard), and the seam: a redirect hook in `settingsPanelStore` that V2 registers per static so `open({tab: 'recruitment'})` never opens the dock, plus `hiddenTabs` on `SettingsPanel`.
- **Task 3 (RH1c):** the Applicants tab: an `applicants` slice in the store with a stale-response guard, third-person reason copy, the shared tier config and reason rows extracted from `FinderCard`, the applicant row with Accept / Decline / Under review / Link to roster and "Full details" opening the existing review modal, empty states.
- **Task 4 (RH1d):** the Listing tab (status card + hosted `DiscoveryTab`) and the V2 Invites tab.
- **Task 5 (RH1d):** entry points (`NotificationCenter`, Home's Recruiting line, the V2 Finder's dead filter options), the Needs-you item, and the doc flips that close Stage 4 after the in-app walk.
